# Qantyrix Tech LLC

> Enterprise Data Engineering, Applied AI/ML Systems, Executive BI Intelligence & Cybersecurity Solutions.

A modern, high-performance web application built with React, React Router, and Vanilla CSS design tokens. Engineered to deliver an executive consulting digital presence matching high-impact modern UI aesthetics.

---

## 🚀 Practice Areas & Core Services

- **Data Analysis & Executive BI:** Multi-source dashboards across Tableau, Power BI, and QuickSight with automated ETL feeds, root-cause anomaly detection, and sub-second reporting latency.
- **Data Engineering & Cloud Pipelines:** High-throughput streaming and batch architectures using Snowflake, AWS RedShift, Google BigQuery, Azure Synapse, and Apache NiFi.
- **AI / ML Engineering & Deep Learning:** Production-grade NLP pipelines, predictive time series forecasting, automated model retraining, and containerized inference APIs with PyTorch.
- **Enterprise Cybersecurity & Compliance:** Zero-trust cloud database hardening, AES-256 encryption, continuous vulnerability assessments, and SOC2 / HIPAA readiness.
- **Cloud Warehouse Modernization:** Deep SQL refactoring, query latency optimization, and legacy database migration (MySQL, SQL Server) to modern cloud data lakes.

## 🛠️ Technology Stack

- **Framework:** React 19 + Vite 8
- **Routing:** React Router v7 (`react-router-dom`)
- **Styling:** Custom Vanilla CSS Design System with CSS variables and responsive bento grids
- **Icons:** Lucide React
- **Typography:** Google Fonts (*Plus Jakarta Sans* & *Playfair Display*)

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v20+ or v22+)
- npm (v10+)

### Installation
```bash
git clone https://github.com/2002apoorv/qantyrix.git
cd qantyrix
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
npm run preview
```
